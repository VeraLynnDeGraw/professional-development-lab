# Professional Development Lab

A professional software development laboratory for building practical AI systems, reusable web systems, and disciplined AI-assisted engineering workflows.

This repository documents a 23-day professional development build focused on creating software that is understandable, testable, reusable, and suitable for real-world use.

---

## Purpose

The purpose of this laboratory is to develop a repeatable professional engineering practice while producing a portfolio of finished software systems.

The laboratory combines:

- Applied artificial intelligence
- Web application development
- Reusable software architecture
- AI-assisted programming
- Testing and validation
- Technical documentation
- Git and GitHub workflows
- Human review of AI-generated work
- Professional project organization

The goal is not simply to generate code.

The goal is to understand, build, test, document, and release software.
